# CNC Hardening Checklist

An interactive checklist generator for hardening CNC machines and manufacturing environments against common security risks.

## 🔗 Live Tool

**https://pareno.github.io/cnc-hardening-checklist/**

## Features

- Interactive checklist covering CNC-specific hardening controls
- Covers network, access control, physical, and operational security
- Copy/export your completed checklist
- Runs entirely in the browser — no data leaves your machine

## Usage

1. Open the [live tool](https://pareno.github.io/cnc-hardening-checklist/)
2. Work through the checklist and tick items as you go
3. Export or copy your results

## Tech

Single-file HTML/CSS/JS. No build step, no dependencies. Deployed via GitHub Pages.
